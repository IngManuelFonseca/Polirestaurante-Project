PoliRestaurante — Sistema de Gestión de Pedidos

Sistema web para la gestión digital de pedidos del restaurante PoliRestaurante, desarrollado como proyecto académico. El sistema busca centralizar y optimizar el proceso de toma, preparación y entrega de pedidos, permitiendo la comunicación en tiempo real entre meseros, cocina y administración.

El proyecto contempla el ciclo de vida completo del software: análisis, diseño, construcción, pruebas y despliegue.

Roles del sistema
Mesero: creación, consulta y entrega de pedidos.
Cocina: visualización y actualización del estado de los pedidos durante su preparación.
Administración: supervisión y consulta de la información general del sistema.
Flujo de los pedidos

PENDIENTE → EN PREPARACIÓN → LISTO → ENTREGADO

Los pedidos también pueden ser CANCELADOS mientras se encuentren en estado PENDIENTE o EN PREPARACIÓN.

Cada cambio de estado queda registrado con su respectiva marca de tiempo, permitiendo realizar posteriormente análisis sobre los tiempos de preparación y atención.

Fases del proyecto
Análisis: requisitos, historias de usuario, casos de uso y diagrama de estados.
Diseño: modelo entidad-relación, diagrama de clases, arquitectura y wireframes.
Construcción: implementación de los módulos de mesero, cocina y administración.
Pruebas: pruebas unitarias, pruebas manuales y trazabilidad con las historias de usuario.
Despliegue: publicación del sistema, manuales de instalación y uso, y demostración funcional.

Proyecto desarrollado para el Politécnico Grancolombiano como parte del proceso académico de desarrollo de software.
